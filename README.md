# L'Îlot (version navigateur)

Jeu de défense de village : le jour on bâtit, la nuit on tient. Export Web (WebGL, Godot 4.6, sans threads).

**Jouer : https://omgprod.github.io/ilot-web/**

- Premier chargement long (le jeu pèse environ 340 Mo), puis le navigateur le garde en cache.
- La partie se sauvegarde dans le navigateur.
- Dans le navigateur, le classement en ligne et la coop ne sont pas disponibles.

Chaque Release contient `ilot-web.zip` (l'export Godot) ; l'Action `pages.yml` le publie sur GitHub Pages.
